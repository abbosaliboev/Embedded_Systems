YOLOv5n on Jetson Nano
엣지 AI (Edge AI)
역할: 사람 실시간 탐지 (5 FPS)
위험구역: 미리 설정한 픽셀 영역 침입 감지
왜 Jetson? GPU 내장 → CPU보다 10× 빠른 추론
왜 YOLOv5n? 소형 모델 → 저지연 (latency) 실시간 처리
🔮
Groq Vision API
Llama 4 Scout 17B
역할: 카메라 영상 → 안전 상황 판단
판단 항목: 화재·연기·PPE·위험요소·사람 위치
왜 Groq? 업계 최고속 LLM 추론 속도 (Ultra-low latency)
왜 Vision? 센서만으로 모르는 맥락을 영상으로 보완

기술적 도전 Technical Challenges
쉽지 않았던 것들 — 직접 해결했습니다
❶ Jetson Nano ARM 패키지 문제
문제: pip로 설치한 OpenCV/NumPy → Illegal instruction 크래시
해결: Python 3.8 가상환경 + ARM 전용 빌드 사용
❷ MQ-2 가스 센서 오경보
문제: GPIO 핀 플로팅 → 항상 가스 감지 상태
해결: 풀업 저항 + 히스테리시스 3회 연속 감지 필터
❸ AI가 센서 데이터 반복 출력
문제: AI가 카메라를 분석하지 않고 센서값만 반복
해결: 프롬프트 재설계 — 시각적 분석만 요청, 센서는 컨텍스트로만 제공
❹ 실시간 스트림 + DB 동시 처리
문제: Flask 단일 스레드에서 SSE + 센서 폴링 + AI 분석 병목
해결: 멀티스레딩 분리 + 비동기 AI 분석 + SSE 큐
