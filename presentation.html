쉽지 않았던 것들 — 직접 해결했습니다
Jetson Nano ARM 패키지 충돌
문제
pip로 설치한 OpenCV/NumPy → Illegal instruction 크래시. ARM64와 x86 빌드 호환 문제
해결
Python 3.8 가상환경 + ARM 전용 cv2 4.13.0 빌드 사용
MQ-2 센서 오경보
문제
GPIO 핀 플로팅 상태 → 항상 가스 감지. 센서 보정 전에도 지속 발생
해결
GPIO 풀업 저항 추가 + 히스테리시스 3회 연속 감지 필터 구현
AI 프롬프트 오작동
문제
AI가 카메라를 분석하지 않고 센서 데이터를 그대로 반복 출력
해결
프롬프트 재설계 — 시각 분석만 요청, 센서는 컨텍스트로만 제공
실시간 처리 병목
문제
Flask 단일 스레드에서 SSE + 센서 폴링 + AI 분석 동시 처리 불가
해결
멀티스레딩 분리 + 비동기 AI 분석 + SSE 큐(maxsize=50) 구현
